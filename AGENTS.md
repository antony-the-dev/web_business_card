### Design decisions (locked)
- **Dark by default, light opt-in via the theme toggle** (same pre-paint + toggle as services.html). The **lightbox stays the always-dark "vault"** regardless of theme: `#pf-lightbox` pins scoped navy tokens (`--ink #eaf2fc`, `--muted #9fb3c9`, `--line rgba(255,255,255,.14)`, `--accent-text #ff5722`) so the panel/media/stamp never flip to light. Blurred artifacts look far better on navy than on white.
- **"Redacted Vault" concept**: real artifact images are pre-blurred BY THE USER at export and shown with no CSS blur (double-blurring read as "muddy"), and carry a mono-uppercase NDA stamp overlay (e.g. `NDA // SANITIZED`, `CONFIDENTIAL — STRUCTURE ONLY`) that only appears in the lightbox (see Status for the locked Sep 5 rule). Hexagon watermark optional. This is a feature, not a workaround — everything is under NDA, and the redaction signals "real work, not internet tutorials". Fits the existing design language perfectly.
