Plain HTML/CSS/JS, no framework. Files: `index.html`, `style.css`, `script.js` (home-page UI + intro), `figure.js` (the glass hero figure — standalone, reused by portfolio.html and 404.html), `lang.js`, plus `portfolio.html`, `404.html`, `privacy.html`, `services.html`, `fonts/` (self-hosted woff2) and `og-portfolio.png`. ## Test
- Local server: `python3 -m http.server 8080` from the project root → http://localhost:8080
- The intro plays once per session; to replay it open a fresh/private tab.
- After editing JS run: `node --check script.js figure.js lang.js`
- **Cache busting**: every page loads `style.css`, `lang.js`, `figure.js`, `script.js` with `?v=YYYYMMDDNN` (currently `2026093004`) (index, portfolio incl. its dynamic figure.js loader, 404, privacy, services). BUMP the version in all pages whenever one of those files changes before a deploy — otherwise browsers mix a fresh HTML page with a stale cached lang.js (Sep 27 2026: the new RAG card showed only its hard-coded bits, "Local LLM" + "tap to inspect", with empty title/desc/type). One-liner: `sed -i '' -E 's/\?v=[0-9]+/?v=NEW/g' *.html`.
- 404.html: GitHub Pages serves it for ANY missing path, so every asset in it is root-absolute (`/style.css`, `/figure.js`…). Locally just open `/404.html`.
